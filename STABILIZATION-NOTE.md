# Living Grimoire VIII — Stabilization

This checkpoint is a performance/refinement pass over the accepted Living Grimoire VII state.

It intentionally does **not** change theorem data, canonical particle geometry, ritual memory semantics, or the selected ambient music.

Primary changes:
- stable, monotonic kinetic decryption with bounded React publication;
- deterministic cipher glyphs between reveal steps;
- removal of whole-tree stage transitions and full-manuscript blur;
- removal of animated filter around the live mirror canvas;
- lighter touch-first shimmer / ambience path;
- animation-frame throttling for Anatomia drag interaction;
- device-profile updates ignore mobile browser-chrome resize noise;
- a performance regression contract is part of `npm run check`.

Physical acceptance should focus on scroll smoothness, theorem transitions, Exegesis reveal, sustained mirror interaction, and Anatomia drag behavior on the Fold.
