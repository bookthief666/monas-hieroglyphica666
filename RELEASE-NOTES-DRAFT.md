# Monas Hieroglyphica — Living Grimoire 1.0 (Draft Release Notes)

This release turns the repository's original shell into the complete Living Grimoire: a 24-theorem, four-register operable manuscript centered on the Living Black Mirror.

## Release highlights

- 24 theorem-specific canonical particle bodies and operative physical laws.
- Touch-first 2D Living Black Mirror with ritual memory, return-state, theorem resonance, and deterministic geometry.
- Lazy desktop WebGL Monad with automatic fallback to the canonical 2D renderer.
- Four registers: Verbum, Exegesis, Operatio, and Anatomia.
- Cross-register geometry metamorphosis and persistent ritual continuity.
- Recovered legacy geometries preserved in the Reliquiae Figurarum rather than replacing canonical theorem bodies.
- Living manuscript marginalia and theorem-specific secondary projections.
- 1564 source witness layer with normalized Latin incipits, facsimile/catalogue links, and explicit separation of project English/commentary from the primary witness.
- Scholar's Margin, theorem memory ladder, alchemical Nigredo/Albedo/Rubedo staging, ambient audio, and procedural Ritual Resonance.
- Fold/mobile performance stabilization, adaptive rendering budgets, reduced-motion behavior, and compositor-cost verification.
- Release-polished I–XXIV theorem rail with touch-sized controls, continuation cues, scroll snapping, and active-theorem centering.

## Verification

The release candidate is gated by `npm run release:check`, which runs geometry/source/continuity verification, performance and release-polish contracts, production release checks, Vite production build, and a high-severity production dependency audit.

## Known limitations / pre-release items

- Full keyboard parity for the gesture-driven Living Black Mirror and individual Anatomia member dragging is deferred as documented P2 accessibility work.
- DuckDuckGo on Android previously showed intermittent compositor flashing; Chrome/Samsung Internet are the canonical Fold QA path for 1.0.
- Public redistribution rights for the current ambient commercial recording must be confirmed, or the recording must be removed/replaced before public release.
- `main` should be protected with a ruleset requiring the `verify` check before merge if repository settings permit.

See `RELEASE-AUDIT.md` for the current release ledger.
